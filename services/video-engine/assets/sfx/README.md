# Built-in SFX (Batch 9)

The only sounds the clipper ever offers as SFX. They are **synthesised,
not recorded** — generated by `scripts/synth-sfx.py` (Python standard
library only, fixed seed, reproducible). No samples were downloaded
from anywhere, and no sound is named that is not in this directory.

- `whoosh.wav` — 0.8s, 48 kHz mono. White noise through a sweeping
  lowpass (300 → 4500 Hz) with a fast attack and smooth decay.
  Plays at the clip start and at each auto-zoom punch-in.
- `pop.wav` — 0.15s, 48 kHz mono. A sine burst sweeping 900 → 350 Hz
  with an exponential decay. Plays on each keyword pop-up.

Regenerate: `python3 scripts/synth-sfx.py`

Per-job setting `sfx`: `none` (default) / `whoosh` / `pop` /
`whoosh_pop`. A trigger that does not exist in a clip (no zoom
moments, no keyword pop-ups) simply does not sound, and the job note
says how many times each fired. At most 8 SFX events per clip.
